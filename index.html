🔧 Configuración inicial

Para que Pablo y Rocío vean los mismos datos (incluso sin internet), la app usa Firebase Firestore. Solo hay que configurarlo una vez en cada celular.

1

Entrar a console.firebase.google.com y crear un proyecto (gratis).

2

En el proyecto → Firestore Database → Crear base de datos → Modo producción → elegir región us-central1.

3

Ir a Configuración del proyecto → Tus apps → Agregar app web (</>) → copiar el objeto firebaseConfig y pegarlo abajo.

4

En Firestore → Reglas pegar esto y publicar:
rules_version='2'; service cloud.firestore { match /databases/{database}/documents { match /{document=**} { allow read, write: if true; } } }

❌ Config inválida. Verificá que sea el objeto firebaseConfig completo.

Esta configuración se guarda en el dispositivo. Hay que hacerlo una sola vez por celular.
